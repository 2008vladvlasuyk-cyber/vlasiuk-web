## Структура

```text
vlasiuk-web/
├── assets/
│   ├── img/
│   │   ├── logo.svg
│   │   └── hero.webp
│   └── fonts/
│       └── .gitkeep
├── css/
│   ├── reset.css
│   └── style.css
├── js/
│   └── main.js
├── pages/
│   ├── about.html
│   └── contacts.html
├── index.html
├── .editorconfig
├── .gitignore
└── README.md
```

`.git/` з’явиться після `git init`; його не потрібно створювати вручну.
Папка `assets/fonts/` зарезервована для майбутніх шрифтів; зараз використовуються системні.
`.gitkeep` зберігає порожню папку у Git, спеціального значення для Git це ім’я не має.

## Запуск

1. Відкрити всю папку `vlasiuk-web` у Visual Studio Code.
2. Встановити Live Server, Prettier і HTMLHint.
3. На `index.html` вибрати **Open with Live Server**.
4. Відкрити `http://127.0.0.1:5500/index.html` (порт може відрізнятися).

Альтернатива, якщо встановлено Python: `python -m http.server 5500 --bind 127.0.0.1` у корені проєкту.
Цей сервер не має автоматичного перезавантаження, тому перевірку Live Reload потрібно виконати саме у Live Server.

## Технології та шляхи

HTML5, CSS3, JavaScript; без залежностей та етапу збирання.
`reset.css` підключається перед `style.css`; `main.js` — з `defer`.
Базовий шрифт у `<style>` залишено за кроком 3 методички, основне оформлення — у `css/style.css`.
На головній використовуються `css/style.css`, `pages/about.html`; у `pages/` — `../css/style.css`, `../index.html`, `contacts.html`.
Відносні шляхи придатні для GitHub Pages у підкаталозі репозиторію.
